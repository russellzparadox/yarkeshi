# یارکشی

جعبه‌ابزار تصمیم‌گیری جمعی برای اندروید. گوشی را وسط جمع بگذارید و قرعه بکشید.

## ابزارها

**با انگشت** (همه انگشت روی صفحه می‌گذارند، دور هر انگشت افکت مایع):
- یارکشی: تقسیم به ۲ تا ۴ تیم
- انتخاب نفر: یک تا سه نفر
- نوبت: ترتیب بازی

**شانس:** شیر یا خط، تاس (۱ تا ۶ تاس)، گردونه با گزینه‌های دلخواه، عدد شانسی

**دور هم:** فلش چرخان، رأی مخفی دست‌به‌دست

همه قرعه‌ها با `crypto.getRandomValues` و rejection sampling کشیده می‌شوند.

## نصب

فایل `release/yarkeshi-3.0.apk` را روی گوشی (اندروید ۵ به بالا) نصب کنید. برنامه آفلاین کار می‌کند.

## ساختار

- `web/index.html`: کل برنامه در یک فایل (HTML/CSS/JS، فونت‌های لاله‌زار و وزیرمتن داخلش)، با WebGL برای مایع و جایگزین Canvas 2D
- `release/`: فایل APK امضاشده (WebView دور همان صفحه)
- `tests/`: تست‌های Playwright در اندازه گوشی

```bash
pip install playwright
python3 tests/test_func.py
```
